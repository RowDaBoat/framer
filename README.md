# Framer

Framer is a small Haskell program to create polyptichs from images I wrote back then in 2017 to create a polyptich for my living room. 

## But why?
Could this be done in PS or Gimp?
> _Probably._

Would I have spent more time PS-ing lots of images because of PS skill-issues?
> Most likely.

Did I have fun learning a bit of Haskell?
> Yes, of course I did.
